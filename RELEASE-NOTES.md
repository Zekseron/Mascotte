# Mascotte 0.9.4 — Mac

Questa release aggiorna **Mac Apple Silicon**. Per **Windows x64** resta disponibile la [0.9.2](https://github.com/Zekseron/Mascotte/releases/tag/v0.9.2): i pacchetti Windows arriveranno dopo il collaudo su Windows.

## Correzioni

- **«apri …» trova anche le app web installate dal browser**, per esempio Google Chat installata da Chrome (cartella «Chrome Apps» dentro Applicazioni).
- **Con Codex o Claude scelti**, se Mascotte non trova l'app, la cartella o il file richiesti lo dice lei, invece di passare la richiesta al servizio, che non può aprire nulla. Le frasi che non sono richieste di apertura vanno al servizio come prima.

Le novità della [0.9.3](https://github.com/Zekseron/Mascotte/releases/tag/v0.9.3) restano: «apri …» per app, cartelle e file con qualsiasi IA scelta, apertura immediata se c'è una sola corrispondenza, programmi e script mai aperti.

## Installare o aggiornare il Mac

- Dalla 0.9.1 in poi usa **Impostazioni → Aggiornamenti → Controlla aggiornamenti**: il pacchetto è firmato con lo stesso certificato personale.
- Per una nuova installazione scarica `Mascotte-Mac-0.9.4-arm64.zip`, estrailo e sposta `Mascotte.app` in Applicazioni; al primo avvio segui il [LEGGIMI](https://github.com/Zekseron/Mascotte/blob/main/LEGGIMI.md) («Apri comunque», una sola volta). Il pacchetto non è notarizzato da Apple.
