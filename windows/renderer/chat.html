Chat con le IA

Per chattare, installa almeno una CLI e accedi al tuo account. Dopo l’installazione riapri Mascotte.

IA locale

      Azioni disponibili con conferma: apri calcolatrice; apri download.

      Memoria locale

      Salva solo le informazioni che vuoi conservare. Le note pertinenti vengono usate dalla chat locale e restano sul PC. Puoi modificarle prima del salvataggio ed eliminarle qui.

      Cartelle visibili alla mascotte

      Con il motore locale la mascotte può leggere l’elenco di queste cartelle: solo nome, tipo, dimensione e data, un solo livello. Nessun file viene aperto o letto. Per esempio: «che file ho in siti?», «quanti pdf ci sono in siti?», «apri siti».

      Hook Codex e Claude

      Collega gli eventi delle sessioni alla mascotte, oppure aggiorna gli hook quando cambia il percorso dell’app. Controlla l’anteprima e applica con backup.
